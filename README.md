# AuthenticationLab (Python)

Небольшая учебная консольная система аутентификации, перенесённая с исходного проекта C#.

## Возможности
- проверка логина и пароля;
- имитация проверки отпечатка пальца;
- проверка QR-кода;
- проверка токена;
- запись событий в `logs/authentication.log`;
- сохранение истории в `authentication.json`;
- модульные тесты на pytest.

## Требования
- Python 3.10 или новее.

## Установка
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск
```bash
python main.py
```

## Тестирование
```bash
pytest -v
```

## Проверка стиля
```bash
flake8 .
```

## Демонстрационные данные
- логин: `maria`
- пароль: `1234`
- отпечаток: `FP-001`
- QR-код: `QR-2026`
- токен: `TOKEN-2026`

Это учебная демонстрация, а не система промышленной безопасности: данные доступа заданы в коде.
